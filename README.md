# Matthieu Heritiana — Portfolio

Personal developer portfolio built with Next.js, showcasing 5+ years of experience in Odoo/ERP development, Elixir/Phoenix, and modern web stacks.

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** CSS (globals.css)
- **Rendering:** Client-side components with canvas animations

## Project Structure

```
my_portfolio/
├── app/
│   ├── layout.tsx       # Root layout & metadata
│   ├── page.tsx         # Home page
│   └── globals.css      # Global styles
├── components/
│   ├── Hero.tsx         # Hero section with 3D orbit canvas
│   ├── Nav.tsx          # Navigation bar
│   ├── Projects.tsx     # Selected work grid
│   ├── Skills.tsx       # Skills with animated bars
│   ├── Contact.tsx      # Contact links section
│   ├── Footer.tsx       # Footer
│   └── BackgroundCanvas.tsx  # Animated background
└── public/              # Static assets
```

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
